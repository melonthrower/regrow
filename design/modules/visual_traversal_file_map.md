## 不变量

- canonical runtime/state/grounding/navigation 不得反向 import `visual_engine.py`。
- Runtime 必须经 `host._register`，保留测试和 M13 monkeypatch seam。
- attempted→executed→landing verified→coverage commit、stateful restore、route 延迟下一轮和 stop reason 时序不能因文件移动改变。
- compatibility shim 只维护旧 import identity；新代码使用 canonical package。

## 2026-07-18 responsibility update

- `agents/effects.py` now contains only `StatefulRiskGuard`; click-effect VLM
  verification and its prompt/export were removed.
- `state/map_guided.py` builds text-only candidate payloads. `state/registration.py`
  owns the default-on two-layer identity fallback and semantic NEW-state scroll.
- `navigation/router.py` passes expected/source context into identify/Back;
  Engine callbacks reuse durable state and perform no read-only block alignment.
- `runtime/landing.py` derives click effect from pHash plus registered identity.
## Transition Observer files

- `agents/observer.py`: read-only before/after transition judgment and
  fail-closed response parsing.
- `prompts/observation.py`: compact mode-specific transition prompt; no graph
  identities or global graph context.
- `runtime/landing.py`: passes only the selected target with the two full
  screenshots, maps `relation_to_target` into existing attempt evidence, and
  persists `observed_outcome + relation_to_target`.

## 2026-07-28 prompt-contract update

- `prompts/grounding.py` defines the formal factual inventory fields
  (`purpose`, immediate effect, visible state/evidence, execution safety, and
  whether available controls change). Formal Qwen replies use `areas/controls`;
  legacy `blocks/result/category/group/scope/interaction` remain parser-only.
- `visual_perception.py` projects the factual contract into internal scheduling
  fields, preserves it through grounding/reconciliation, and fails closed on
  missing or unsafe execution evidence.
- `prompts/exploration.py`, `prompts/observation.py`, and
  `prompts/navigation.py` consume factual descriptions instead of exposing
  internal category/group labels. Reverse Edge Explorer uses the same two-image
  contract in Region-lazy and whole-page modes; there is no candidate-table or
  framework-fixed return split.
