# regrow 方法动画

默认入口 `dist/index.html` 是180秒、15幕的无声字幕动画。用 GNOME 官方文件管理器、设置和日历截图说明各环节；标注、光标、任务卡与知识关系是讲解编排，不是模型原答或框架实跑。

点击播放可自动推进；支持暂停、拖动、章节跳转、倍速与含播放器的全屏。可离线直接打开；建议桌面或横屏观看。手机竖屏为整体画布缩放，文字较小。键盘焦点在按钮时遵循原生按钮行为，可用可见播放键暂停。

`dist/slides.html` 保留最初15页静态讲稿，包含两个独立历史Clock批次的真实截图与证据边界；与动画中的公开素材分开。两版本不构成同一冻结框架的端到端实验。

素材与许可按 `dist/film/assets/sources.json` 的官方来源页记录。原图未修改，框线由网页独立叠加。外部参考视频受访问限制，未观看完整影片；视觉方向参考用户提供的截图，不声称复刻影片节奏。

验证：JavaScript语法；Chromium 15幕素材、时间轴、播放暂停、章节跳转、结尾停止、全屏控制条、光标尺寸与手机横向布局；陌生读者独立阅读和意图对照。仅演示网页验证，没有新增模型或应用GUI实验。复杂组合、功能目录质量和训练收益仍待研究验证。

本Site创建为私有。用户已明确授权上传演示及历史Clock截图，后续指示使用公开网上图片讲解。GitHub源导出不含截图，完整离线版及核验记录见交付包。
