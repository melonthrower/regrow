# 取消区块父子关系：实施前审阅稿

状态：设计候选，框架/Prompt/运行图/队列均未修改；0 新 Luna、0 GUI。用户已授权取消父子关系，Prompt 完整候选待确认后实施。不因产物生成而宣称行为通过。

区块之间保留真实访问关系及其动作、条件和结果证据，不持久保存物理包含父级。Region 身份、功能职责、控件引用（允许共享身份）、knowledge、tasks、当前前景观察保持原职责。当前布局的包含/覆盖/显隐仍可用于界面理解，不转成永久父子边。同屏共现不推断跳转，访问关系不自动生成反向返回。

## 各阶段共享合同

|阶段|取消的行为|保留的行为|
|---|---|---|
|全局/局部发现|parent/parent_index 输出、父级引用和父子环校验|先辨认区块、再在指定功能范围登记控件，复用稳定身份|
|发现暂缓/补登记|父级未确认导致其他已确认区块连带暂缓|每个区块自身身份、控件自身归属及必要访问目标仍须确认|
|动作/目标补齐|追溯父级作为必需对象、沿祖先链检查|实际来源区块、目标控件及访问目标的证据要求|
|调度/返回|凭持久父子边过滤前景候选|当前观察、原任务归属、真实访问来路、实际动作关系；不新增返回边|
|正常/纠错呈现|物理包含树、parent 名称转换及相关报错|Region 内嵌 controls 的格式；共享控件唯一归属报错另案修复，不能称本改动已解决|
|读取/发布|旧 parent_region 进入当前 Region 对象并继续写入新快照|只在 Region 对象加载边界丢弃退役字段；旧快照、原请求原答和动作证据原样留存|
|历史合同续接|不把旧格式字段恢复为当前图关系|已发请求沿原合同纠错和解析；旧 parent 可以读取但不进入新对象关系；按原已发 schema/name_contract 决定是否仍需父字段转换，不新建双管线|
|导航和目录|不添加隐式物理父级|已验证访问边、多入口、条件、断开组件和目录引用均保留；阅读树只是图的投影|

旧图不批量改写，不重编号、不移动控件和任务。采用新源码后，加载时仅忽略 Region 的退役父级字段，正常发布的新快照不含它；原始观察/历史回复中的 parent_index 保留为历史证据。partition_children 是事后拆分谱系，不是物理包含边，本批不删除。task_routing.parent_region 当前计算的是访问来路而非 parent_region 字段，保留其行为并改为清楚的来路命名，避免把有效导航误删。

## 最小验收

先实现再验证。辅助检查只覆盖父级字段退出及相邻的控件引用/任务归属/访问边。使用真实运行副本，由正常发现及动作后更新入口构造完整请求，保留原任务、历史、范围和截图；实际 Luna 原答未经修改，走正常校验/纠错/登记。检查新对象无父级字段、稳定 ID 和共享引用保持、访问边有来源证据。补登记案例须确认某区块自身明确时不再因另一容器未确认而连带暂缓；不能用手改模型回复代替验收。

正常旧图加载/新快照发布验证：旧原件不改，控件/任务/访问边不变，仅退役 Region 字段不再进入新对象。保留一份旧合同失败/纠错案例，确认其沿实际已发合同续接而不恢复持久父级。执行前按最少案例选择可覆盖的实际记录；保存帧验收不声称真实导航成功。

完成聚焦检查后进行陌生读者独立审阅、意图对照，再补代表性原生 Luna 验证；保留失败和纠错历史。未获 Prompt 确认前不修改源文件，不部署队列，不清理既有错误访问边。

## 边界

点位核对、共享控件纠错、动作后视觉误读、系统辅助应用范围均属另外的问题。本改动不因取消父级便宣称它们已解决。下游生成/采集本轮不改；取消包含边不意味着必要前置条件可跳过。

## 旧合同和当前材料的具体边界

named_references.prepare 已有 name_contract 时直接复用；decode 依据该合同解析。新请求的 schema 不含 parent_index，因此 wire_schema 不产生 parent。对于实际已发送、仍含父字段的旧合同，保留相应 parent→parent_index 接收、原纠错稿呈现及其必要索引转换；只用于原调用续接，不写入 Region.parent_region，不让历史字段影响新一轮调度/接纳。proposal_revision 的旧原稿引用重排也须按实际旧合同保留必要处理。不能笼统删除全部旧协议转换。

活动 page_context 生成平列区块材料，退出物理 children 结构及相关几何包含缺口；现有 page_context.current_tree 包装键先保留，内容改为平列 Region 列表，节点只组织自己的 controls，不再产生 children 包含关系。page_context._display 内的 tree（L187/L227） 不再要求每个节点带 children，可按已有可选列表方式读取，保证旧已发上下文仍可显示。target_observation 与 region_scroll 已使用 node.get("children", [])，平列输入可以直接使用，先核对相邻合同，不为此新增转换层或强制重写消费者；region_scroll 的提示“当前区块树”改为“当前区块列表”。environment_context 的访问图目录仍保留树状阅读投影；它的显示展开关系不写回图。动态文字变化也纳入本次 Prompt 审阅：删除“已登记子区块（独立探索，详情折叠）”及数量行、删除“包含它的区块”条目、移除物理包含树缩进；滚动提示中“当前区块树”改为“当前区块列表”。这些变化不删区块本身或已观察的访问来路。
