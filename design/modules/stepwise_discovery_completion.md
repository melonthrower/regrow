# 临时逐步遍历器：同图增量登记

范围：仅 `experiments/clock_manual_20260919` 的发现步，不更改主框架、动作结算或原运行图。

- `discovery_step.commit` 先检查整体结构/归属错误，将身份未确认对象及其依赖留作缺口，复用原物化和裁图保存能够独立确认的对象。原请求/回复不覆盖，记录中的 `source_field` 仍指原回复索引。
- `discovery_completion` 随知识快照原子保存同图哈希、原请求、累计已登记对象、缺口及调用回执。部分登记保持 discover，不推进扫描、不唤醒任务、不提供完整可执行前景；全部旧缺口明确处理后按累计前景执行原收尾。当前同图工作集内相同调用回放复用回执。
- 补全只看原截图。`completion_updates` 对每个唯一可读缺口标签填写 registered / excluded / unresolved 和依据；registered 必须指向本批可登记的同种对象。unresolved 可引用本批仍未确认的行更新描述；没有引用则保留旧项。新增同名缺口另取唯一标签，省略旧项不能关闭它。
- 已登记 same 区块/控件行仅作容器或去重引用，不覆盖原父关系/描述、不重复追加观察；需要修订旧事实仍走纠错。控件列表代表项按累计已登记控件检查。新发现照常提交，不清空已登记集合。
- `discovery_completion.retrieve` 对缺口先召回同名及身份说明中明确提名的记录（不合并同名歧义），均无命中才按名称、描述和控件文字重叠召回，最多5项；文字检索不证明身份/可见性，不保证跨语言召回。全局补全不披露工作菜单的控件；局部只披露相关和已登记控件身份。
- 固定补全手册位于 `遍历prompt/发现手册/增量补全.prompt`。动态内容含实际回执、待补项、检索候选和范围。历史纠错疑问明确作为过去原因，不能冒充当前仍缺的信息。

当前验证见本月日志。保存截图调用不是GUI执行；代码实现不自动切换各队列已冻结的运行版本。
