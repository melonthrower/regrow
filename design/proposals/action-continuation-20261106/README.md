# 任务合同与动作后接续

本批将已确认的Task Prompt与运行合同一起接通，复用既有调度和执行链。

| 责任 | 已实现行为 |
|---|---|
| 任务 | new_tasks每项仅control/target；target原文保存，state为done/pending/blocked；旧任务仍按原完成条件及真实阻塞读取。 |
| Action合同 | 普通选择、恢复及调用级next_action复用完整可执行动作参数；不再保存逐任务建议。 |
| 主结果与候选 | 主更新按正常对象/任务合同登记；坏next_action单独进入原动作纠错，不回滚有效上一结果。 |
| 来源 | 记录真实更新call/next_action、已接受后图observation/snapshot与原任务，不伪造选择调用。 |
| 派发与恢复 | 正常恢复、调度及action_ready之后消费一次，再走原绑定、目标核对、执行和结果登记；任务或后图失效撤销。 |

next_action只服务当前原任务；必要准备仍保持原归属。done/blocked、任务切换、异常、历史复核或历史补登记不接续。暂停作业也重查任务/图并沿原投递前流程复核；未知投递仍只续登记/观察，不重放。没有新增CLI开关或第二条GUI流程。

本批接线在本地组合中的三项聚焦检查、两份完整真实保存帧及正常候选接收有限通过；重复登记未重新挂候选。0新GUI，尚未验证实际点击效果或长遍历。一次失败轮次的准备条件判断/引用错误保留为未接受；未以新候选放宽旧前提。其他已有探索质量、身份及应用边界风险见[已知问题](../../../KNOWN_ISSUES.md)。

公开分支原有共享角色正文保持原样，与上述保存帧组合不同；未重新验证整套公开Prompt组合。
