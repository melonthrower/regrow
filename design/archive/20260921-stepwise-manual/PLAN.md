# 临时框架各阶段手册化实施计划

目标：按用户认可的发现手册形式，整理动作、更新、异常恢复和流程纠错；说明字段及正反例，去掉旧任务措辞补丁。只修改experiments/clock_manual_20260919，不改原框架。

- 核对现行调用入口及schema，不改变动作空间、回复schema、登记/恢复路由或额度。
- 动作：任务与证据、目标观察、探索原则、共享动作空间及字段、选择/输出核对。
- 更新：结果观察、区块变化、回复字段、条件附加任务结果核对；前后图不混为当前设备状态。
- 恢复：临时恢复目标、异常分类、恢复选择、复用动作字段、回复填写；异常消失回发现。
- 纠错：错误核对、开放能力、执行证据边界、字段填写及候选消歧。
- 先用组装测试检查手册章节、字段解释、原schema不变；再以已保存各阶段请求生成完整阅读稿。不开设备、不重写历史。
- 更新实验设计和prompt索引，同步暂停的临时框架并保存源版本。提交本次独立修改，不混入旧输入探索改动。

技术：现有Python请求构造器、JSON流程清单、UTF-8 prompt模块；复用原测试与证据记录目录。无额外模型角色。
