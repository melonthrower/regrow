# 动作输出条件映射

对应prompts/output.py action_shape：

| 条件 | 展开文案 |
|---|---|
| schema包含complete | complete、products |
| schema包含none且包含complete | none |
| schema包含none且不含complete | none_without_complete |
| none含task_update | none_with_task；外层reason与task_update.reason按此分支区分 |
| none不含task_update | none_reason |
| none不含task_update且包含complete | 额外none_progress |

带task_update和不带task_update是互斥的输出合同。审阅稿将它们分标题，不是同时要求模型填两种形状。具体字段枚举仍由本次Schema决定。
