# 区块功能登记字段底稿

这是静态Schema的字段展开，正常调用可能按模式、任务和已有对象进一步收窄；不是最终请求字段表。

| 字段路径 | 原合同 |
|---|---|
| `$.functions` | 必填；array |
| `$.functions[].name` | 必填；string |
| `$.functions[].description` | 必填；string |
| `$.functions[].constraints` | 必填；array |
| `$.functions[].unconfirmed` | 必填；array |
| `$.functions[].object` | 必填；string |
| `$.functions[].completion` | 必填；string |
| `$.functions[].supports` | 必填；array |
| `$.evidence` | 必填；string |
| `$.local_knowledge` | 必填；object |
| `$.local_knowledge.update` | 可选；array |
| `$.local_knowledge.update[].id` | 必填；string |
| `$.local_knowledge.update[].text` | 必填；string |
| `$.local_knowledge.add` | 可选；array |
| `$.local_knowledge.delete` | 可选；array |
| `$.parameter_definitions` | 必填；array |
| `$.parameter_definitions[].ref` | 必填；string |
| `$.parameter_definitions[].description` | 必填；string |
