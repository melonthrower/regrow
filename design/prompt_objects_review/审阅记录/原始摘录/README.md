# 四对象说明拆分审阅稿

本轮只整理现有说明，未接入运行Prompt，没有改变模型请求、字段、调度或原历史。旧运行来源仍在src/regrow/prompts。本目录是暂时的逐对象审阅入口，不是第二套已启用维护源；审完再决定接线和退役重复内容。

- [控件](控件.prompt)：知识、条件、参数、外观、跳转、入口与探索判断。
- [区块](区块.prompt)：身份、包含、成员、区块知识及功能。
- [任务](任务.prompt)：任务提出、状态判断、答案与准备依赖。
- [动作](动作.prompt)：提案参数、真实结果及归属。

每段保留原文、来源行范围和散列；跨对象段落集中一处并交叉引用，混合语境不假称已纯化。解释/例子缺口列在各稿开头，后续再补。控件稿开头单列用户最新确认的入口措辞，未冒充已写入运行源。

来源映射.json用于逐段追溯，原文件清单.json记录未迁入文件；配置原文.json保留动态任务目标/动作输出文案。并非完整Schema或全部持久字段目录，未列内容不可据此删除。旧任务/任务登记与补全.prompt含handling、equivalent、entry等旧合同，未整体搬作新定义；仍可由原文件清单查找。

这轮不决定每步读写对象的组合方式。审阅顺序：控件→区块→任务→动作；通过后再收拢引用，避免并行维护。
