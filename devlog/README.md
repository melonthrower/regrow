# 每日开发记录

看今天推进了什么、卡在哪里、下次从哪里继续，从这里开始。

- 一天一份 `YYYY-MM-DD.md`，同一天持续补记，每批工作交付前更新；新增日期时将下方索引按日期倒序添加。
- 每项写清做了什么、结果和验证范围，并给模块文档、月度日志、提交或证据位置。未实现、未验证、失败和已通过分开写；后续解决用补记说明，不抹去原失败。
- 每页末尾保留当天收尾时的未解决问题、下一步；跨日看最新一页。没有可靠依据就不填总进度、耗时或成功率。
- 每日日志记录进展；现行合同仍查 `design/modules/`，详细命令和批次验证仍查 `design/changelog/`。这里链接原记录，不复制长篇设计、prompt或模型回复。
- 日期沿用项目工作记录，历史补记注明来源；不把未核实的旧工作编成日记，不搬动原实验。
- 日志可随源码导出；只写证据的路径/批次标识，不把截图、原始运行记录、凭据或私有端点放进源码仓库。运行证据在本地工作区根，可能不在活动checkout或GitHub导出中。
