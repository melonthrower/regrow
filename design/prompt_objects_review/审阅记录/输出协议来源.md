# 输出协议说明来源

新增调用说明/输出协议中的十份正文为从正常生产入口现有字段与说明整理的可读文字，不是旧文件逐字摘录，也未接入运行。无需让读者从程序常量猜回复字段。

- 选择身份候选/核对控件身份：recognition/control_identity_review.py，selection_request / attach。
- 复查控件归属：recognition/ownership_review.py，request。
- 暂挂与切换分支：tools/branch_switch.py，request构造中的schema。
- 复核旧共享关系：records/shared_control_review.py，纠错字段构造（resolution/record_edit/blocked_by/proposal）。
- 恢复中断：traversal/recovery.py，schema及validate。
- 补充观察：traversal/repair_stages.py，补观察请求构造。
- 补齐对象外观：traversal/object_registration.py，request。
- 复核任务结果：traversal/task_result_review.py，request。
- 原步骤纠错：traversal/step_repair.py及纠错/步骤纠正.prompt，沿原请求和能力表。

动态候选枚举、原任务/对象引用、开放修正能力仍依本次记录决定；没有发明一组通用ID或声称静态例子覆盖全部分支。
