# 区块探索任务字段底稿

这是静态Schema的字段展开，正常调用可能按模式、任务和已有对象进一步收窄；不是最终请求字段表。

| 字段路径 | 原合同 |
|---|---|
| `$.inventory` | 必填；string；取值 ["complete", "partial", "uncertain"] |
| `$.evidence` | 必填；string |
| `$.operations` | 必填；array |
| `$.operations[].control` | 必填；string |
| `$.operations[].name` | 必填；string |
| `$.operations[].action` | 必填；string；取值 ["click", "double_click", "long_press", "input_text", "scroll", "key_press", "hotkey", "hover", "right_click", "drag"] |
| `$.operations[].handling` | 必填；string；取值 ["explore", "record", "equivalent", "defer"] |
| `$.operations[].reason` | 必填；string |
| `$.operations[].equivalent_to` | 必填；string |
| `$.operations[].task_type` | 必填；string；取值 ["single_action", "parameter", "scroll"] |
