# Local graph and lexical retrieval

Approved goal: replace growing global prompt indexes with source/neighbour retrieval and small local BM25 fallback; bound knowledge context without deleting facts. No dense model or external vector database. Root implements and reviews; Terra may only observe actual model/screenshot evidence.

1. Freeze a saved-case evaluation manifest from existing calls before tuning. Only known landing references already present in each pre-response ledger qualify. Historical responses are weak labels; visually verify selected cases and distinguish candidate recall from semantic decision errors. Target >=95% known-landing recall and zero invalid references, with sample count and misses reported. New screens must not be forced to reuse a candidate.
2. Implement local retrieval over State/Region occurrence descriptions and actual control/operation text, with language-neutral Latin tokens plus CJK characters/bigrams. BM25 only ranks candidates; it cannot merge identities or authorize clicks. Prioritize pending source/current, task source, latest real incoming return and verified route. Select neighbours and bounded global text matches; no global index in model input.
3. Add optional context_query for observation-only lookup when local candidates do not match. Preserve pending and its before frame; no location/settlement/GUI mutation in a lookup turn. Repeated identical queries are rejected through existing correction budget, and distinct requests are bounded per observation. Default query uses pending target or task description. No new model role.
4. Bound retrieved historical JSON separately, then enforce a total dynamic text byte budget without clipping protected current controls/pending/correction fields. Byte accounting is explicit, not billed-token accounting; overflow stops before a paid request with a concrete gap. Avoid requiring tokenizer network assets.
5. TDD retrieval recall/ordering, irrelevant-history growth, multilingual lexical match, missing query match, budget/required refs, parser and runtime pending lookup. Run affected adjacent tests only. Measure same saved requests; inspect misses rather than redefining labels.
6. Use a bounded native continuation after checks, preserve source ledgers and evidence, count every role HTTP, and retain STOP/retry. Report semantic observations separately from automated weak-label recall. Update module docs/index/alignment/changelog and commit only verified task-owned files.

Execution outcome: implemented explicit control cards, field-aware queries, historical names and Region anchor ranking; 294 focused tests passed. Calibration/held-out labels were subsequently used in development, so final 33/33 is a diagnostic recall check, not an independent acceptance score. Earlier saved-frame identity errors retained; batch15 8 HTTP/3 GUI gave a limited correct identity/return example with one corrected hover no_effect.
