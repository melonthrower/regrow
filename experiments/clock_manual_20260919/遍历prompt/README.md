# Prompt 入口索引

开发定位见[模块目录](../../../design/modules/stepwise/README.md)。此页只索引提示组装，规则和状态看对应模块；完整实际请求以run/calls为准。

当前三步主链由程序按阶段组装，不把本目录所有文件一起发送。

| 阶段 | 入口 | 固定模块 |
|---|---|---|
| 发现与定位 | discovery_step.prepare | 工作区块定位/当前区块重定位 + 发现手册5部分 |
| 任务清点 | region_tasks.plan_request | 区块探索任务 + 输入与搜索探索正反例 |
| 动作选择 | stepwise_flow + region_tasks | 流程02所列模块；导航时附探索导航路线 |
| 动作后更新 | update_step.build_update_request | 流程03 + 列表代表项 + 异常识别；有任务时附任务结果核对 |
| 功能登记 | region_functions.request | 区块功能登记 + 单区块任务规则/正反例 |
| 异常恢复 | recovery.build_request | 恢复当前探索 + 异常识别 + 恢复策略 + 共享动作空间 + 恢复输出 |
| 流程纠错 | step_repair.request | 步骤纠正 + 探索验证原则；动作纠错附目标观察，多候选时附控件候选消歧 |

`输出格式/*.schema`有些是基础模板，程序会补入本轮字段和候选名称；检查合同应看最终请求的response_schema。system_prompt为已拼好的固定模块，user_prompt为动态信息，fixed_parts仅用于追溯，不重复发送。

`流程/01_发现.json`仅供独立保存帧assemble入口使用，区别于当前discovery_step的局部/全局定位流程。

以下8份文件未在当前临时Python入口或流程配置找到直接装配引用，保留供历史查阅，不作为主链规则，不应手动混入新请求：

- 任务/动作后Region增量.prompt
- 动作/单步动作建议.prompt
- 动作/结果核对.prompt
- 历史上下文/区块探索披露.prompt
- 历史上下文/记忆增量.prompt
- 历史上下文/读取规则.prompt
- 身份比较/区块与控件复认.prompt
- 身份比较/跨图身份比较.prompt

历史调用与快照不追改；将来若重新接入这些模块，需要先对齐该阶段字段，不能把旧Page/source_ref/记忆编号规则直接并入当前Region流程。

三步主流程是发现与登记 → 动作选择与执行 → 结果观察与更新。程序负责校验、实际投递与持久登记；回复不是执行结果。异常恢复选择恢复界面的动作，结束后回发现步；流程纠错只修正失败提案或记录，不直接执行GUI。

动态输入来自已有图、动作记录和本轮图片匹配；固定prompt不填写本轮位置或伪造历史。候选框统一为整屏坐标。后台引用、匹配指标和预算由程序保存，不把预算计数塞进模型正文。未知功能本身不构成异常；要验证的属性不能同时被设为必须已验证的前提。
