# 识别、遍历、记录

当前源码：`src/regrow/`。三部分是代码职责，不是每轮固定三次模型调用。

| 部分 | 工作 | 定位 |
|---|---|---|
| 识别 | 读当前截图、核对旧身份、补新对象 | [识别](recognition.md) |
| 遍历 | 保留当前任务，提出问题、选动作、核对结果，处理恢复 | [遍历](traversal.md) |
| 记录 | 保存对象/任务/动作知识，提供当前工作所需历史 | [记录](records.md) |
| 支撑 | 模型、平台、预算、原始证据、提示与工具 | [运行](runtime.md) |

主线：读取相关记录 → 按需识别/提出任务 → 推进原任务 → 核对并登记 → 继续。已投递未登记动作先续登记；不因恢复重做动作。对象变化与动作结果可以由同一份回复处理。
