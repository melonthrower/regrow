# Prompt 维护入口

每类调用的主正文位于 [调用/](调用/)，对应关系在 [流程/调用组成.json](流程/调用组成.json) 的 `calls.<role>.template`。先看 [修改指引](修改指引.md) 定位正文、字段合同和材料生产位置。

正常发送和工作台预览统一经过 `runtime/model_transport.prepare_request` → `prompts/output.prepare`：选择本次主模板，填实际字段/动作合同/示例，再加入运行范围及本次已提供的专用补充。旧对象块选择、requires展开和Markdown章节重排不再参与该出口。任务类型的业务定义仍由原负责模块读取，不能因退出提示拼接而删除。

角色和运行范围只在system出现一次；user继续由原材料生产入口提供任务、记录、历史与图片，不从模板猜授权。纠错沿用被拒回复当时的原步骤合同，外加当前纠错能力和诊断；身份比较和共享核对使用自己的窄合同。

本地接入正在验证：已从真实记录完成“选择下一步”原生预览；尚未据此接受Luna行为或部署到原实机运行。来源及后续结果记录在 `artifacts/runs/prompt_template_integration_20261025_01/`。之前审阅稿及体量表保留在 `prompt_calls_review_20261025_01`，其数字不是本次实际发送体量。
