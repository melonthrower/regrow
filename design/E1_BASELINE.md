| 项目 | 固定值 |
| --- | --- |
| 共同底座 | Qwen3-VL-8B-Instruct，四个原始权重分片按历史 SHA256 核验 |
| 组别 | 原模型、State 数据微调、Region 数据微调；两种微调独立从同一原模型开始 |
| OSWorld | 固定提交 `7a17d3abc86d524420ea4ec96752f84d245fea74`，Ubuntu/Docker |
| 任务 | 361项，排除明确列出的8项Google Drive任务；补回旧批额外排除的Chrome恢复标签任务 |
| 输入与执行 | 纯截图、原Qwen3VLAgent及其computer_use→pyautogui转换；相对坐标0–1000 |
| 截图 | 实际1280×800；不可把旧CLI声明1920×1080当成真实尺寸 |
| 每任务预算 | 最多15轮Agent决策、1次任务尝试；单轮可有多个底层GUI命令 |
| 历史与等待 | 最近4轮截图/回复，另保留更早动作的文字汇总；每次执行后等待3秒 |
| 推理服务 | vLLM 0.11.2，BF16，上下文65536，单序列，最多5张图，seed=0 |
| 采样 | temperature=0.7、top_p=0.8、top_k=20、repetition_penalty=1.0；每回复最多32768 tokens |
| 测试信息 | 三组均不额外提供Region/State图、探索经验或测试任务答案 |

原API适配器没有发送temperature/top_p，实际采用服务端generation_config；CLI的0/0.9不生效。CLI的max_trajectory_length=3同样没有传入Agent，实际history_n=4；它只限制最近带截图/回复的历史窗口，更早动作仍进入Previous actions文字汇总，不是丢弃所有四轮以前的信息。以旧服务日志、固定源码和保存帧为证据；后续所有组共享冻结的[模型配置](../experiments/osworld_e1_20260923/model_configs.json)，不能随微调输出目录的默认配置改变采样。

主指标是官方评估器连续分数的均值，不把任意正分或summary.status=success当作任务成功。361项均有有效评分后才报告完整主成绩。单列满分、部分得分、零分和缺评分数。基础设施/评估器异常保留原证据；处理后如需重试，另存尝试和预先统一的重试规则，不挑最好结果。API最多5次传输尝试不等于任务pass@5。

8项Drive排除遵循[OSWorld官方允许的361项口径](https://osworld-v1.xlang.ai/)，版本更换必须另建基线。训练配置和等量数据预算尚待训练前冻结，不因本次固定推理协议而算训练已接通。
